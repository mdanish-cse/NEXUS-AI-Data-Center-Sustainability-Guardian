# Coolara — Pre-existing materials

This folder is the register of materials prepared before the official build
window. It contains planning and disclosure documentation only; it does not
contain application source code, database migrations, synthetic demo data,
production prompts, or deployment artefacts.

## Contents

- `PRD.md` — product requirements and MVP scope.
- `PROJECT_CONTEXT.md` — challenge context, scope, and team roles.
- `PRE_BUILD_CHECKLIST.md` — readiness checklist for before and during the build window.
- `TEAM_WORK_SPLIT.md` — two-person team work plan.
- `PRE_EXISTING_CODE_DISCLOSURE.md` — pre-existing work boundary.
- `README_DISCLOSURE_TEMPLATE.md` — final submission disclosure template.
- `AI_TOOLS_DISCLOSURE.md` — AI tools/models and verification checklist.

## Important boundary

The Coolara implementation—including UI, API routes, database schema and
migrations, demo telemetry, detection engine, simulator, AI integration, and
deployment—must be recorded as work completed during the build window, subject
to the official event rules.

The hackathon rules are the source of truth. Before submission, review this
folder and complete every field marked `[confirm]` honestly.
